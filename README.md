Включение основной программы minibank через команду Старт
Далее следовать указанию терминала используя доступные команды, например: Баланс, Внесение, Снятие и Выход
При вводе команды будет доступен функционал банковского приложения.

Использованы команды такие как Class (создание класса),Construction (создание объекта через ключевые слова),прописаны Function для вызова меню отвечающие на вопросы пользователя, изменен цвет вывода ошибки на главный экран, вывод неопределенных команд выделен отдельным цветом
